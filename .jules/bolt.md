## 2024-06-11 - [Native Math for NumPy Mean in High-Frequency Loops]
**Learning:** In high-frequency Computer Vision loops (e.g., frame-by-frame feature extraction), using NumPy aggregation functions like `np.mean` on very small native Python lists introduces substantial performance overhead compared to standard Python operations like `sum(list) / len(list)` due to type-checking and dispatch latency.
**Action:** Use native math for small, fixed-size lists to avoid type-checking and dispatch latency when optimizing small array operations in fast-running algorithms like those in `src/features/extractor.py`.
