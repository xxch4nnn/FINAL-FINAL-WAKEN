## 2024-06-05 - Optimize Feature Engineering Calculations
**Learning:** `HandFeatureExtractor` makes repeated calls to `np.array` to create 2-element arrays representing points, and then uses `np.sqrt` with integer conversion for calculating euclidean distance. In Python, instantiating small NumPy arrays inside a hot loop (like processing a live camera feed) incurs significant overhead compared to using standard tuples. Furthermore, using `math.hypot` on scalar values is faster than squaring and adding and then taking the square root via NumPy for 2D points. The 'reference logic' for distance states `int(p1[0]-p2[0])**2`, which `math.hypot(int(p1[0]-p2[0]), int(...)` replicates perfectly as `math.sqrt(dx**2 + dy**2)`.
**Action:** Replace `np.array` with tuples in `_to_pixel` and use `math.hypot` in `_get_euclidean` to significantly speed up distance calculations in the hot live frame loop, avoiding the overhead of creating many small arrays per frame without altering the mathematical result.
