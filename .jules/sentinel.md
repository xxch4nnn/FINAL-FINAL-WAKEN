## 2024-05-19 - Insecure Deserialization in Machine Learning Models
**Vulnerability:** The live vision engine script (`src/runtime/vision_engine.py`) used `pickle.load()` to deserialize the XGBoost model. Python's `pickle` module is not secure against erroneous or maliciously constructed data. An attacker could craft a malicious `.pkl` model file that executes arbitrary code when loaded.
**Learning:** `pickle` is often used out of convenience in data science workflows, especially with libraries like `joblib`. However, deploying models loaded via `pickle` presents a significant remote code execution (RCE) risk. Machine learning frameworks often have their own secure serialization formats (like XGBoost's `.json` format) that do not evaluate serialized data as executable code.
**Prevention:** Avoid using `pickle`, `joblib.load`, or `numpy.load(allow_pickle=True)` for loading untrusted artifacts. Instead, use secure, specialized methods provided by ML frameworks (e.g., `model.load_model('model.json')` in XGBoost) or secure serialization libraries like `safetensors`.
