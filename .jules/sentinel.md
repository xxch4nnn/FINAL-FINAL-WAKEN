## 2024-05-24 - Fix Insecure Deserialization in ML Models
**Vulnerability:** The codebase was using `pickle` and `joblib` to deserialize machine learning artifacts (models, scalers, and feature lists) directly from the filesystem. These serialization formats allow arbitrary code execution during deserialization, which represents a critical security risk if the files are tampered with.
**Learning:** `joblib` and `pickle` are common in machine learning prototyping but should never be used in production environments for loading untrusted files. XGBoost models and other artifacts must be saved using secure formats like JSON.
**Prevention:** Use `.json` formats and native ML framework save/load methods (like `clf.save_model(path)` and `xgb.XGBClassifier().load_model(path)`). For utility objects like scikit-learn standard scalers, extract the necessary parameters (`mean` and `scale`) and load them explicitly using the standard `json` library rather than relying on `joblib`.
