## 2024-05-24 - OpenCV Text Legibility & Keyboard Discoverability
**Learning:** In computer vision applications drawing directly onto unpredictable live camera feeds, standard `cv2.putText` often becomes illegible against similar background colors, creating a poor user experience. Furthermore, essential keyboard controls are often undocumented in the UI, leading to poor discoverability and forcing users to read source code or documentation to exit or control the app.
**Action:** Always use a 'text outline' technique (draw thick black text, then thin white/colored text on top) to guarantee contrast regardless of background. Always explicitly render essential keyboard shortcuts (like `[Q] Quit` or `[ESC] Exit`) directly on-screen, positioned at the top of the frame to prevent UI overlap.
