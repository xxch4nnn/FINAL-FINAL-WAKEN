## 2024-11-20 - Dynamic Camera Feed Text Contrast and Shortcut Discoverability
**Learning:** We observed that WCAG contrast guidelines can be difficult to satisfy on dynamic camera feeds because the background can be arbitrarily bright or dark at different pixels and over time. Therefore, plain colored text drawn via `cv2.putText` often blends in, harming accessibility. In addition, the different keyboard shortcuts across the various runtime scripts (`q`, `ESC`, `c`, `SPACE`) are confusing and not easily discoverable to users, leading to a poor User Experience.
**Action:** To guarantee contrast against any dynamic background, we must use a custom `draw_text_with_outline` function that renders a black outline (or background) around the text. Furthermore, the UI must explicitly and persistently render the script-specific on-screen keyboard shortcuts at the top of the viewport (e.g., `(10, 30)`) for discoverability.
